# AI Usage

## Tools Used
ChatGPT was used during this exercise.

## What it was used for
Used mainly to clarify the problem requirements, generate initial boilerplate for the TCP server, and assist with debugging issues such as imports, encoding errors, and parsing edge cases. It was also helpful for exploring different approaches to parsing syslog and JSON inputs.

## What was written vs. generated

The core implementation, including the project structure, format detection, parsing flow, and schema mapping logic, was written and organized independently. This includes handling nested JSON fields, extracting relevant values, and mapping them into the normalized schema.

AI-assisted code and suggestions were used as references and adapted as needed. The final implementation reflects decisions made after testing different approaches and validating outputs against the provided sample data.

## Notes

AI was used as a support tool to speed up development and troubleshooting. The solution was reviewed, tested locally, and adjusted to ensure correctness and alignment with the expected output.
